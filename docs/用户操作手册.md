## 1. 平台概览

管理中心是平台的数据底座和系统设置入口，通过左侧导航菜单访问各功能模块。

**入口**：点击主页面右上角的「管理中心」按钮进入。

**导航菜单分为三大板块**：

| 板块 | 包含功能 | 用途说明 |
|------|---------|---------|
| **数据管理** | 数据源、物理表、指标、维度、视图、字典 | 管理平台的数据资产，是问数功能的基础 |
| **系统配置** | 模型配置、问数配置 | 配置 AI 模型和查询参数，影响问数体验 |
| **高级模块** | AIR、CAN、BIG | 进阶功能，本手册暂不展开 |

## 2. 数据管理

数据管理是问数平台的基础。只有正确配置了数据源、物理表、视图、指标和维度，问数功能才能将自然语言问题转化为准确的数据查询。

> **配置顺序建议**：数据源 → 物理表 → 视图 → 维度 → 指标 → 字典

### 2.1 数据源管理

**功能说明**：数据源是您业务数据库的连接配置。平台通过数据源连接到您的数据库来读取数据。

#### 2.1.1 新增数据源

1. 在左侧菜单中点击「数据源管理」
2. 点击右上角 **「新增数据源」** 按钮
3. 在弹出的表单中填写以下信息：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 数据源名称 | 必填 | 给数据源起一个便于识别的名字，如「销售数据库」 |
| 数据库类型 | 必填 | 选择数据库类型：PostgreSQL / MySQL / ClickHouse / 瀚高 HighGo / 达梦 Dameng |
| 主机地址 | 选填 | 数据库服务器的 IP 地址或域名，默认 localhost |
| 端口 | 选填 | 数据库端口号，选择数据库类型后自动填入默认端口（PostgreSQL: 5432、MySQL: 3306、ClickHouse: 8123、瀚高: 5866、达梦: 5236） |
| 用户名 | 选填 | 数据库登录用户名 |
| 密码 | 选填 | 数据库登录密码 |
| 数据库名 | 必填 | 要连接的数据库名称 |
| Schema | 选填 | PostgreSQL / 瀚高可填写；瀚高不填时默认只使用与数据库名相同的 Schema |

4. 填写完成后，可点击密码下方的 **「测试连接」** 按钮验证是否可以成功连接
5. 测试通过后，点击 **「确定」** 保存

#### 2.1.2 管理数据源

在数据源列表中，每行数据源提供以下操作：

| 操作 | 说明 |
|------|------|
| 测试连接 | 验证当前数据源是否可以正常连接 |
| 编辑 | 修改数据源配置（编辑时密码显示为 ******，如需修改请重新输入） |
| 删除 | 删除数据源（需二次确认） |

#### 2.1.3 数据源状态说明

| 状态 | 颜色 | 含义 |
|------|------|------|
| 正常 | 绿色 | 连接测试成功，可正常使用 |
| 未连接 | 灰色 | 刚创建，尚未进行连接测试 |
| 错误 | 红色 | 连接测试失败，请检查配置信息 |

### 2.2 物理表管理

**功能说明**：物理表是您数据库中实际存在的表。平台需要先同步物理表信息，才能基于这些表配置视图、指标和维度。

#### 2.2.1 页面布局

页面分为左右两部分：
- **左侧**：数据源列表（显示每个数据源的名称、状态和包含的物理表数量）
- **右侧**：选中数据源下的物理表列表

#### 2.2.2 同步物理表

1. 在左侧点击一个数据源
2. 右侧会分页加载该数据源下已同步的物理表
3. 点击右侧的 **「同步物理表」** 按钮手动刷新数据库表结构
4. 同步任务会在后台执行，页面会轮询显示进度，完成后刷新物理表列表

> 首次使用时，建议先完成数据源的「测试连接」确保连接正常，再同步物理表。进入物理表页面不会自动同步，避免大规模数据库元数据扫描导致页面卡顿。
> 物理表列表默认分页加载，字段明细在点击“查看字段”或编辑时按需加载。

#### 2.2.3 新增物理表

1. 选择数据源后，点击 **「新增」** 按钮
2. 填写以下信息：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 数据源 | 必填 | 自动选中当前数据源，不可修改 |
| 数据集名称 | 必填 | 给物理表起一个业务名称，如「订单明细表」 |
| 物理表名 | 必填 | 数据库中的实际表名，如 `t_order_detail` |
| Schema | 选填 | 数据库 Schema，默认为 `public` |
| 描述 | 选填 | 对该表的业务说明 |

3. 点击 **「从数据源同步」** 可自动获取该表的字段信息
4. 也可以手动点击 **「添加字段」** 逐个添加字段（字段名、类型、可空、备注）
5. 点击 **「确定」** 保存

#### 2.2.4 其他操作

| 操作 | 说明 |
|------|------|
| 查看字段 | 查看物理表包含的所有字段信息（字段名、类型、可空、备注） |
| 编辑 | 修改物理表配置信息 |
| 删除 | 删除物理表（需二次确认） |
| 搜索 | 在搜索框中输入关键字，可按表名或描述快速筛选 |

> 在指标、维度、字典和视图设计器中选择物理表时，下拉框会先显示当前数据源的首批物理表；如果目标表不在列表中，可直接输入表名关键字进行远程搜索。编辑已有配置时，即使原物理表不在首屏，也会按记录自动加载并回显。

### 2.3 指标管理

**功能说明**：指标是业务中关注的可量化数值，如「销售额」「订单量」「客单价」等。正确配置指标是问数功能准确理解您业务问题的关键。

#### 2.3.1 指标类型说明

| 类型 | 说明 | 举例 |
|------|------|------|
| **基础指标** | 直接从数据库表中通过聚合计算得到的指标 | 销售总额 = SUM(金额)、订单数量 = COUNT(订单ID) |
| **派生指标** | 在基础指标上增加时间限定、业务筛选或衍生计算 | 近30天销售额、上月订单量、同比增长率 |
| **复合指标** | 通过多个指标组合计算得到的新指标 | 客单价 = 销售额 / 订单数 |

#### 2.3.2 新增基础指标

1. 点击右上角 **「新增指标」** 按钮
2. 左侧选择 **「基础指标」** 类型
3. **选择数据来源**：
   - **物理表**：选择数据源 → 选择物理表
   - **视图**：直接选择已创建的视图
4. **配置统计方式**：

   **方式一：使用字段**（推荐）
   - 选择聚合函数：SUM（求和）、COUNT（计数）、AVG（平均值）、MAX（最大值）、MIN（最小值）、COUNT_DISTINCT（去重计数）
   - 选择度量字段：从物理表的字段列表中选择要聚合的字段

   **方式二：使用表达式**
   - 直接输入 SQL 聚合表达式，如 `sum(if(type='A', amount, 0))`

5. **可选配置**：
   - 指标日期标识：选择日期字段，用于时间维度分析
   - 半累加指标：开启后可选择「期末值」或「期初值」，适用于余额类指标
   - 分析维度：选择该指标关联的可分析维度（影响问数时的维度推荐）

6. **右侧填写基础属性**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 指标名称 | 必填 | 英文或拼音标识，如 `sales_amount` |
| 指标展示名 | 必填 | 中文名称，如「销售额」 |
| 单位 | 选填 | 元 / 个 / % / 其他 |
| 业务口径 | 选填 | 描述指标的业务定义和计算逻辑 |
| 同义词 | 选填 | 输入后回车添加，如输入「营收」作为「销售额」的同义表达 |

7. 点击 **「确定」** 保存

#### 2.3.3 新增派生指标

1. 选择 **「派生指标」** 类型
2. 选择一个基础指标或复合指标作为原始指标
3. 配置衍生参数：

| 参数 | 说明 |
|------|------|
| 时间限定 | 如 `LAST_30_DAYS`（近30天） |
| 业务限定 | 添加筛选条件（字段 + 运算符 + 值），如 `status = '已完成'`；多值条件使用 `IN / NOT IN`，输入一个值后回车生成一个标签，也可粘贴逗号分隔值；空值条件使用 `IS NULL / IS NOT NULL`，不需要填写值 |
| 衍生方式 | 无 / 同比 / 环比 / 同比增长率 / 环比增长率 |

4. 填写基础属性（同基础指标）
5. 点击 **「确定」** 保存

#### 2.3.4 新增复合指标

1. 选择 **「复合指标」** 类型
2. 在「复合表达式」中输入组合公式，使用 `[指标名]` 引用已有指标，如：
   - `[销售额] / [订单数]`（客单价）
   - `[本月销售额] - [上月销售额]`（环比增长额）
3. 填写基础属性（同基础指标）
4. 点击 **「确定」** 保存

#### 2.3.5 管理指标

列表顶部提供类型筛选按钮（全部 / 基础指标 / 派生指标 / 复合指标），方便快速查找。

每行操作：
- **血缘**：查看该指标的依赖关系图
- **编辑**：修改指标配置
- **删除**：删除指标（需二次确认）

### 2.4 维度管理

**功能说明**：维度是分析数据的角度，如「按地区」「按时间」「按产品类别」。维度帮助您从不同角度查看指标数据。

#### 2.4.1 维度类型说明

| 类型 | 说明 | 举例 |
|------|------|------|
| 普通 | 一般分类维度 | 产品名称、部门名称 |
| 时间 | 日期/时间维度 | 订单日期、创建时间 |
| 地理 | 地理位置维度 | 省份、城市 |
| 分类 | 枚举分类维度 | 订单状态（已完成/已取消） |
| 数值 | 数值分段维度 | 年龄段、价格区间 |

#### 2.4.2 新增维度

1. 点击右上角 **「新增维度」** 按钮
2. **选择数据来源**：
   - **物理表**：选择数据源 → 选择物理表
   - **视图**：直接选择已创建的视图
3. 填写基本信息：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 维度名称 | 必填 | 英文或拼音标识，如 `region` |
| 显示名称 | 选填 | 中文名称，如「地区」 |
| 物理字段 | 必填 | 从物理表的字段列表中选择对应的数据库字段（选择后会自动推断数据类型） |
| 数据类型 | 选填 | 字符串 / 数值 / 日期 / 日期时间（选择物理字段后自动推断） |
| 维度类型 | 必填 | 普通 / 时间 / 地理 / 分类 / 数值 |
| 同义词 | 选填 | 输入后回车添加 |
| 描述 | 选填 | 维度的业务说明 |

4. **时间维度额外配置**（仅当维度类型选择「时间」时显示）：

| 字段 | 说明 |
|------|------|
| 默认格式 | 该时间维度的默认展示格式，如 `YYYY-MM-DD` |
| 可选格式列表 | 除默认格式外，还支持的其他格式，如 `YYYY-MM`、`YYYY` |

5. 点击 **「确定」** 保存

#### 2.4.3 管理维度

每行操作：
- **编辑**：修改维度配置
- **删除**：删除维度（需二次确认）

### 2.5 视图管理

**功能说明**：视图是将物理表按业务关系重新组织后的逻辑数据集，可用于统一跨表分析口径、简化指标与维度配置，并为问数与生成接口提供更稳定的字段语义。

> 建议在关键物理表梳理完成后，优先完成视图建模，再继续配置维度、指标和引用视图字典。

#### 2.5.1 页面入口与布局

**入口**：管理中心 → 数据管理 → 视图管理

页面主要分为两部分：
- **左侧**：视图分类树，可按分类快速筛选视图，也可新增分类
- **右侧**：视图列表，可按数据源筛选，并执行新建、编辑、预览、删除等操作

列表中每条视图通常展示：
- 分类
- 视图名称
- 显示名称
- 视图类型
- 字段数量
- 描述
- 更新时间

#### 2.5.2 视图类型说明

当前系统后端支持以下 3 类视图：

| 类型 | 说明 | 适用场景 |
|------|------|------|
| 单表 | 基于单个物理表构建逻辑视图 | 单表即可满足分析需求的场景 |
| 多表聚合 | 基于多张物理表配置关联关系 | 指标与维度分布在不同表，需要统一分析口径 |
| 自定义 SQL | 通过 SQL 直接定义逻辑结果集 | 复杂逻辑无法通过简单拖拽快速表达时 |

> 当前前端设计器中，常用的可操作模式为 **可视化设计（多表聚合）** 和 **SQL 编辑（自定义 SQL）**。

#### 2.5.3 视图列表常用操作

| 操作 | 说明 |
|------|------|
| 新建视图 | 进入视图设计页面新建逻辑视图 |
| 编辑 | 修改视图结构、字段配置和基本信息 |
| 预览 | 查看生成的 SQL 和样例数据 |
| 删除 | 删除视图（如已被指标或维度引用，通常需要先解除引用） |
| 新增分类 | 在左侧分类树中新增分类节点 |

#### 2.5.4 新建多表聚合视图

1. 点击 **「新建视图」** 进入设计页面
2. 在顶部保持 **「可视化设计」** 模式
3. 左侧先选择一个数据源
4. 将需要的物理表拖拽到中间画布
   - 左侧物理表列表默认显示首批表
   - 可在搜索框输入表名关键字，搜索结果只显示匹配表
   - 清空搜索后恢复默认列表
5. 点击字段建立表之间的连线关系
6. 在右侧 **「关联配置」** 中确认：
   - JOIN 类型
   - 左右表字段对应关系
   - 必要的过滤条件
7. 在右侧 **「字段列表」** 中勾选需要保留的字段，并配置字段属性
8. 在 **「基本信息」** 中填写视图名称、显示名称、分类和描述
9. 先执行预览确认结果，再点击 **「保存」**

#### 2.5.5 新建自定义 SQL 视图

1. 点击 **「新建视图」** 进入设计页面
2. 将顶部模式切换为 **「SQL 编辑」**
3. 输入自定义 SQL 查询语句
4. 如需检查结构，可尝试执行“转为可视化”或后续直接预览结果
5. 填写视图名称、显示名称、分类和描述
6. 先预览，再保存

> 自定义 SQL 适合复杂业务逻辑，但建议控制输出字段数量，并确保字段名称对业务人员可理解。

#### 2.5.6 视图字段配置

视图保存前，建议在右侧 **「字段列表」** 中完善以下信息：

| 配置项 | 说明 |
|------|------|
| 展示名称 | 用户在后续配置和问数中更容易理解的字段名 |
| 字段说明 | 补充字段业务含义，减少歧义 |
| 可过滤 | 标记该字段可作为问数或生成 API 的过滤参数 |
| 值域配置 | 当前常用为枚举值或字典映射，便于后续参数选择和调试 |

建议优先完善以下字段：
- 时间字段
- 状态字段
- 地区/组织字段
- 需要作为接口参数的字段

#### 2.5.7 分类与默认视图

- 视图建议按行业域、业务专题或交付对象分类管理
- 左侧分类树可新增分类，并查看各分类下的视图数量
- 未分类视图适合临时调试，不建议作为长期交付状态
- 已保存的视图可在编辑页设置为 **默认视图**，便于查询页优先使用

#### 2.5.8 预览与验收建议

保存视图前，至少完成一次预览，重点确认：
- 生成 SQL 是否符合预期
- 返回字段名称是否可读
- 样例数据是否正常
- 字段是否足以支持后续维度、指标和字典配置

#### 2.5.9 与后续配置的关系

视图通常会继续用于以下场景：
- **维度管理**：维度可直接基于视图字段配置
- **指标管理**：指标可直接基于视图字段进行聚合或表达式计算
- **字典管理**：字典可引用视图中的值字段和标签字段
- **问数与生成 API**：查询结果与接口配置会沿用当前视图上下文

### 2.6 字典管理

**功能说明**：字典用于管理业务中的枚举值和编码映射，帮助问数系统正确理解业务术语。例如，将数据库中的状态码 `1/2/3` 映射为「待处理/进行中/已完成」。

#### 2.6.1 字典类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| **手动配置** | 手动维护值和标签的映射关系 | 枚举值较少且固定的场景，如订单状态 |
| **引用视图** | 从已创建的视图中动态获取可选值 | 枚举值存储在数据库表中的场景 |
| **自动生成** | 从物理表的指定字段中自动提取去重值 | 需要定期更新的枚举值 |

#### 2.6.2 新增手动配置字典

1. 点击 **「新增字典」** 按钮
2. 填写基本信息（字典名称、显示名称）
3. 选择字典类型为 **「手动配置」**
4. 在映射配置表格中逐行添加：

| 列 | 说明 |
|----|------|
| 实际值 | 数据库中存储的原始值，如 `1` |
| 展示标签 | 用户看到的友好名称，如「待处理」 |
| 同义词 | 可选，输入后回车添加 |

5. 点击 **「确定」** 保存

#### 2.6.3 新增引用视图字典

1. 选择字典类型为 **「引用视图」**
2. 选择要引用的视图
3. 选择 **值字段**（对应实际值）和 **标签字段**（对应展示标签）
4. 点击 **「确定」** 保存

> 引用视图类型的字典会动态从视图查询最新可选值，无需手动维护。

#### 2.6.4 新增自动生成字典

1. 选择字典类型为 **「自动生成」**
2. 依次选择数据源 → 物理表 → 字段
3. 可选：开启筛选条件，添加过滤规则（字段 + 运算符 + 值）
4. 点击 **「确定」** 保存

> 自动生成类型的字典会从指定表字段查询去重值。创建后可通过 **「同步」** 按钮随时更新。

#### 2.6.5 值管理

在字典列表中点击 **「值管理」** 可查看和管理该字典的所有映射值：
- 手动配置类型：支持添加、编辑（双击标签）、删除值
- 自动生成类型：支持 **「同步」** 按钮刷新最新值
- 所有类型均支持按值或标签搜索

## 3. 系统配置

### 3.1 模型配置

**功能说明**：模型配置用于管理问数平台使用的 AI 大语言模型（LLM）。平台通过 AI 模型来理解用户的自然语言问题，并生成对应的数据查询。

> 系统必须至少配置一个可用的模型，问数功能才能正常使用。

#### 3.1.1 新增模型配置

1. 在左侧菜单中点击「模型配置」
2. 点击右上角 **「新增配置」** 按钮
3. 在弹出的表单中填写：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 配置名称 | 必填 | 给配置起个名字，如「生产环境 GPT-4o」 |
| 模型供应商 | 必填 | 点击选择 AI 服务提供商（如 OpenAI、DeepSeek 等），以 Chip 标签形式展示，点击即选中 |
| 模型名称 | 必填 | 从下拉列表选择或手动输入模型名称。可点击「获取最新」从供应商 API 同步最新可用模型列表 |
| API Key | 条件必填 | 部分供应商需要填写（如 OpenAI），编辑时不会回显已有密钥，如需修改请重新输入 |
| API 地址 | 条件必填 | 部分供应商需要填写自定义 API 地址（如私有化部署的模型） |
| 启用状态 | 选填 | 开关控制，默认开启 |

4. **高级参数**（折叠面板，通常无需修改）：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| Temperature | 控制回答的随机性，值越低回答越确定性 | 0.7 |
| Max Tokens | 单次回答的最大长度 | 4096 |

5. 点击 **「确定」** 保存

#### 3.1.2 供应商选择说明

供应商以分组 Chip 标签形式展示：
- 常用供应商（如 OpenAI、DeepSeek）直接展示
- 其他供应商在「其他」分组中，默认显示前10个，可展开查看更多
- 可使用搜索框快速查找供应商

> 不同供应商对 API Key 和 API 地址的要求不同，选择供应商后表单会自动显示或隐藏相应字段。

#### 3.1.3 管理模型配置

列表中每行显示配置名称、供应商、模型名称、连接状态和启用状态。

| 操作 | 说明 |
|------|------|
| 测试连接 | 验证该模型配置是否可以正常调用 AI 服务 |
| 设为默认 | 将该模型设为系统默认模型（问数时优先使用） |
| 编辑 | 修改模型配置 |
| 删除 | 删除模型配置（需二次确认） |

> 建议配置完成后，对每个模型执行一次「测试连接」，确认配置正确。页面加载时会自动测试默认模型的连接状态。

#### 3.1.4 状态说明

- **已启用**（绿色）：该模型正在使用中
- **未启用**（灰色）：该模型已停用
- **默认**（蓝色标签）：该模型是系统默认模型
- **连接状态**：已连接 / 未连接 / 测试中

### 3.2 问数配置

**功能说明**：问数配置用于调整平台查询相关的全局参数。目前支持配置时间格式化类型。

#### 3.2.1 时间格式化配置

时间格式化类型决定了问数时时间维度可以按什么粒度展示。

**页面操作**：
- 直接在表格中行内编辑，修改后点击右上角 **「保存配置」** 即可

**表格字段说明**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 格式名称 | 必填 | 时间格式，如 `YYYY-MM-DD`（按天）、`YYYY-MM`（按月）、`YYYY`（按年） |
| 显示标签 | 必填 | 在界面上展示的中文名称，如「按天」「按月」「按年」 |

| 操作 | - | 删除该格式 |

**添加新格式**：点击「添加格式」按钮，在表格底部新增一行空记录，直接填写。

> **提示**：格式名称和后缀标识需要与后端解析逻辑保持对应，建议由技术人员协助配置。后缀标识会用于生成衍生维度名称。

## 4. 查询与结果使用

### 4.1 Agent 查询

Agent 查询是当前默认首页，适合日常问数、连续追问和结果解释。

**入口**：系统首页 `/agent-query`

#### 4.1.1 开始新对话

1. 点击左侧栏 **「新建对话」**
2. 在输入框中输入自然语言问题，例如“最近30天各街道上报量趋势”
3. 按回车或点击发送，系统开始流式分析

#### 4.1.2 查看分析过程和结果

查询完成后，页面会依次展示：

| 区域 | 说明 |
|------|------|
| 分析步骤 | 展示意图识别、生成、校验、执行、解释等处理过程 |
| 结果卡片 | 展示查询结果表格或图表 |
| 元信息面板 | 展示时间范围、指标、维度、过滤条件 |
| 底部操作区 | 展示生成 API / API 调试等结果扩展能力 |

#### 4.1.3 常用结果操作

在结果卡片右上方可进行以下操作：

| 操作 | 用途说明 |
|------|---------|
| 引用 | 将本次查询的 MQL 作为上下文，继续做补充分析或条件调整 |
| 查看SQL | 查看当前查询生成的 SQL |
| 维度细分 | 在当前结果基础上增加维度细分 |
| 调整查询 | 对当前查询条件和展示方式进行调整 |
| 图表 / 表格 | 在图表和表格两种视图之间切换 |

4. 系统会结合上一次的查询上下文继续生成结果

> 适用场景：连续追问、在原查询基础上增减条件、补充维度分析。

## 5. 生成接口与在线调试

平台支持将查询结果进一步封装成可对外调用的接口，方便行业线业务系统对接。

### 5.1 配置输出格式

在查询结果上点击 **「生成API」** 前，需要先配置输出格式。

配置弹窗包含两部分：

| 配置项 | 说明 |
|------|------|
| 目标格式示例 | 输入期望返回的 JSON 示例，最外层必须是数组 `[]` |
| API所需参数 | 从可过滤字段中选择参数，或手工输入自定义参数名称 |

#### 5.1.1 目标格式示例填写要求

- 必须为合法 JSON
- 最外层必须为数组
- 建议保留业务系统实际需要的字段，不要直接暴露所有明细列
- 建议字段名使用明确业务含义，例如 `street_name`、`report_count`

#### 5.1.2 API 参数选择建议

- 优先选择查询中确实会用到的过滤字段
- 参数名应简洁、稳定、便于外部系统理解
- 同一接口的参数命名保持统一，不要混用中文、英文和别名
- 如当前查询绑定了视图，建议优先选择该视图中已开启“可过滤”的字段作为 API 参数

---

### 5.2 生成接口

1. 先完成一次有效查询
2. 在结果卡片底部点击 **「生成API」**
3. 填写目标格式示例和 API 所需参数
4. 点击保存后，系统生成对应的数据格式配置
5. 生成成功后，结果卡片底部会显示接口名称，并将按钮切换为 **「API调试」**

生成时，系统会结合当前查询的：
- 自然语言问题
- MQL
- SQL
- 查询结果样本
- 当前绑定视图 ID（如有）

这些信息共同生成可复用的动态接口配置。

---

### 5.3 API 调试与重新生成

接口生成成功后，点击 **「API调试」** 可打开调试弹窗。

调试弹窗包含以下内容：

| 区域 | 说明 |
|------|------|
| API 端点 | 展示生成后的接口路径，可复制 |
| 请求参数 | 根据参数配置自动生成输入项；如存在字典值，会以下拉方式展示 |
| 请求示例 | 自动生成本次请求体示例 |
| 响应结果 | 展示接口调用结果、成功/失败状态、耗时 |

#### 5.3.1 在线调试步骤

1. 打开 **「API调试」**
2. 填写或选择参数值
3. 点击 **「发送请求」**
4. 查看返回结果和耗时
5. 如需提供给第三方系统，可复制接口端点并结合接口文档使用

#### 5.3.2 重新生成

如果发现接口结构、参数映射或转换脚本不符合预期，可在调试窗口点击 **「重新生成」**：

- 系统会基于当前配置重新生成接口信息
- 重新生成后会自动刷新接口文档与参数配置
- 建议重新生成后再次执行一次在线调试确认结果

## 常见问题

### Q: 问数时提示「未配置模型」怎么办？
请前往「系统配置 → 模型配置」，确保至少有一个已启用的模型配置，且该模型的连接测试通过。

### Q: 数据源连接测试失败怎么办？
请检查：
1. 主机地址和端口是否正确
2. 用户名和密码是否正确
3. 数据库名是否存在
4. 网络是否通畅（如防火墙是否放行）

### Q: 同义词有什么用？
同义词帮助 AI 理解不同的业务表达方式。例如为指标「销售额」添加同义词「营收」「收入」后，用户无论用哪个词提问，系统都能正确识别。

### Q: 数据管理的配置顺序是什么？
建议按 **数据源 → 物理表 → 视图 → 维度 → 指标 → 字典** 的顺序配置。先完成数据连接和基础表梳理，再通过视图把跨表关系和字段口径整理清楚，随后基于视图或物理表配置维度、指标，最后补充字典等术语映射。

### Q: 修改配置后需要重启系统吗？
不需要。所有配置修改保存后立即生效。
